RIT BusTrack is a college transportation app that allows students to:
• Track college buses live
• View bus routes and stops

• Find the nearest bus
• Request a temporary pickup location
• Suggest a new permanent bus stop
• Receive bus notifications

DESIGN DIRECTION:
Make this look like a professionally designed real-world transportation application, NOT an AI-generated UI and NOT a typical college project.

Reference the usability and information hierarchy of professional transit/navigation applications.

Use:
• Clean white and very light neutral backgrounds
• Deep blue as the primary brand color
• RIT-inspired blue accents
• Black/dark navy typography
• Subtle borders
• Very limited shadows
• Professional icons
• Consistent 8px spacing system
• Strong alignment
• Generous whitespace
• Clear typography hierarchy

Avoid:
• Excessive gradients
• Excessive rounded cards
• Huge buttons
• Random decorative graphics
• Excessive glassmorphism
• Neon colors
• 3D illustrations
• Generic AI dashboard designs
• Too many floating elements
• Unnecessary animations
